## Model comparison and limitations

The fixed eight-case factual comparison returned eight correct, grounded responses
from Gemini 3.5 Flash-Lite. Gemini 3.8 Flash returned three correct, grounded
responses and five failed requests under the current request deadlines. Successful
responses from both models matched the expected labels; this is insufficient to
claim general grading superiority. The default model was retained; optional
`GEMINI_GRADING_MODEL` routing is available. See the tracked benchmark JSON.

AI-reviewed bank keys have not received human expert certification. Deterministic
checks verify supported final results, not all prose or arbitrary candidate code.
Question randomness is constrained by role, level, coverage and prior use; finite
pool exhaustion can reuse questions from older sessions. Session state remains in
memory; download before closing. Physical devices, paid media, arbitrary-language
code execution, a broad expert rubric benchmark and distributed account quotas
are not established by these checks.

including retained compatibility routes and offline authoring/evaluation scripts.
