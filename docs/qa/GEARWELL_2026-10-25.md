# Gearwell integration verification — October 25, 2026

Scope: imported frontend, live interviewer voice, lifecycle and preservation of
the existing interview engine. Tests use synthetic or generic fictional text;
no physical camera/microphone or personal media was used.

- Live ElevenLabs questions completed in both conversational and individual
  modes using the supplied voice ID. Individual advancement generated the next
  question through the same controller. Keys were not returned to the browser.
- A synthetic 640×360 moving camera stream ran through the real conversation
  engine. The corner video was playing while the avatar reported
  `speaking=true`, `mouthOpen=0.064` and the UI reported interviewer playback.
  Listening started after audio completion. Finishing cleared the camera and
  retained a downloadable full-session recording. Silent generated audio
  correctly produced no invented transcript or score.
- Technical individual practice accepted a fictional answer and advanced through
  three questions to the report. This local-only check correctly disclosed that
  semantic factual grading needed AI consent. Existing factual/grading tests
  cover consented accuracy behavior; no new live Gemini grading benchmark is
  claimed for this frontend migration.
- Report transition verified `room.hidden=true`, computed display `none`, report
  visible, and mouth closed. This caught and fixed a desktop CSS specificity bug.
- Browser initialization caught and fixed a portal-mount replacement bug;
  memoizing the imported shell preserves its imperative avatar/camera mounts.
- The landing page was visually inspected at desktop size and in a 390-pixel
  iframe viewport. Physical mobile devices and their autoplay policies were not
  tested. Desktop screenshots are retained locally under `outputs/gearwell-qa/`.
- Automated tests cover exact fixed voice/model forwarding, no key leakage,
  consent/origin/size rejection, streamed body cancellation, sanitized failures,
  invalid audio, actual playback events, autoplay retry without regeneration,
  cancellation and stale-event protection, Worker routing, shared camera reuse,
  cancellation and reopening.

Final required checks: 151 tests, TypeScript and production build. The temporary
`/qa-gearwell` and `/qa-mobile` routes are removed before the final build.
Reusable synthetic-camera source remains under `web/tests/fixtures/`.

Known limits: playback-driven mouth animation is not phoneme synchronization;
existing large model/bundle build warnings remain. Hosted deployment and a
physical-device end-to-end recording check are not claimed.
