# Cadence web app

React/Vinext interview practice studio, with a Cloudflare Worker backend.

Run `pnpm install` then `pnpm dev`. Run `pnpm test`, `pnpm exec tsc --noEmit`, and `pnpm build` to verify.

The default is practice mode: curated questions, optional recordings, manually reviewed transcripts, transparent rubric feedback, and downloadable answer clips. Live AI is optional and requires a server-side API key and explicit cloud-processing consent.

See the repository root README, TEAM_CONTEXT.md, and docs/ for contracts, privacy boundaries, and the demo checklist.
