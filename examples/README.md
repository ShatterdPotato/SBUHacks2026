# Fictional interview test resume

`fictional-ai-ml-resume.txt` and `fictional-ai-ml-resume.pdf` contain the same
invented AI/ML internship profile. Every person, organization, project, and metric
is fictional. They contain no real applicant information or API credentials.

In Cadence choose **Use your resume** and upload either file. The PDF should show
about 4,198 extracted characters, including footer text. Review the extraction.

- **My real experience** exercises the private personal-mode flow: generic AI
  topic questions if enabled, browser rubric for answers.
- **A fictional sample** permits sending this invented text and made-up answers
  to Gemini for AI questions and feedback after cloud consent.

Do not replace these fixtures with a real person's resume in Git.
